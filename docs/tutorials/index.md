# Eğitimler (Tutorials)

> **Diátaxis kategorisi:** Tutorials; *öğrenme odaklı, baştan sona el tutan anlatımlar.*

How-to rehberlerinden farkı: how-to **bilen** birinin belirli bir işi yapmasına yardım eder, tutorial **bilmeyen** birine sistemi öğretir. Tutorial okuyucunun ne bildiğini varsaymaz ve sonunda çalışan bir şey bırakır.
